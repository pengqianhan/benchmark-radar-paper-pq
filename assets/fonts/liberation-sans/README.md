# Figure fonts

Unmodified Liberation Sans 2.1.5 regular and italic fonts, vendored for the
reproducible taxonomy figures. This Helvetica-compatible sans serif matches
the style of the paper's Helvetica/Nimbus Sans figure text. All titles and
labels use normal weight, following the taxonomy PDFs in `origin/main`.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

License: SIL Open Font License 1.1, reproduced in `LICENSE`; attribution is in
`AUTHORS`. No operating-system font or font download is needed at build time.
